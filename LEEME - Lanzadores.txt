Sistema Stock - Lanzadores

No hace falta abrir ninguna consola. Solo doble clic.

Si Windows muestra "la directiva de grupo bloquea este programa" al abrir los
archivos .vbs, usá los archivos .bat (hacen lo mismo):

- "Iniciar Sistema Stock.bat"  (o el .vbs)
  Arranca la base de datos y el sistema, y abre el navegador en
  http://localhost:3000

- "Reiniciar Sistema Stock.bat"  (o el .vbs)
  Úsalo si la página deja de responder o después de una actualización.
  Reinicia solo el sistema; la base de datos queda corriendo.

- "Detener Sistema Stock.bat"  (o el .vbs)
  Apaga el sistema. La base de datos queda corriendo.

Importante:
- Ejecutalos en la PC donde está instalado el sistema.
- Usá la misma cuenta de Windows con la que se instaló.
- Los .bat pueden mostrar una consola por un instante; se cierra sola.

Los registros quedan en la carpeta "logs".
